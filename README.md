# NET NEWS - منصة الأخبار الذكية والمتطورة

منصة إخبارية عصرية ومتكاملة مبنية باستخدام React وTypeScript وTailwind CSS مع تكامل مباشر ولحظي مع Google Firebase (Firestore & Firebase Storage).

---

## 🌟 أبرز المميزات

1. **مزامنة تلقائية ولحظية مع Firebase**:
   - حفظ فوري ومباشر لجميع التعديلات (المقالات، الأخبار العاجلة، الأقسام، الإعدادات).
   - مؤشر مرئي لحالة المزامنة المباشرة (`synced`, `syncing`, `pending`, `offline`).
   - دعم كامل للعمل بدون اتصال (Offline Support) مع طابور مزامنة آمن وإعادة محاولة تلقائية دون تكرار العمليات.

2. **نظام إدارة المقالات والمحتوى الإخباري**:
   - إضافة وتعديل وحذف المقالات وتحديد حالتها (منشور / مسودة).
   - رفع صور المقالات مباشرة وحفظها على Firebase Storage مع المعاينة الفورية.
   - شريط إخباري للأخبار العاجلة متزامن لحظياً.

3. **إحصائيات الزوار المتقدمة (Real-time Analytics)**:
   - تتبع دقيق للمشاهدات، الجلسات، والزوار الفعليين (بدون أرقام وهمية).
   - إحصائيات لفترات متعددة: آخر 12 ساعة، 24 ساعة، 7 أيام، 30 يوماً، وسنة كاملة.
   - عداد الزوار النشطين حالياً في الوقت الفعلي.

4. **لوحة تحكم إدارية شاملة**:
   - تسجيل دخول آمن للمدير عبر Firebase Authentication.
   - إدارة الأقسام والتصنيفات وتفعيل/تعطيل العرض.
   - إدارة المشتركين في النشرة البريدية وسجل التدقيق والعمليات (Audit Log).
   - إعدادات الهوية والموقع وSEO.

5. **تصميم احترافي وسريع الاستجابة**:
   - واجهة مستخدم متناسقة وأنيقة تدعم اللغة العربية واتجاه RTL بالكامل.
   - بطاقات إخبارية، أقسام متخصصة، نافذة قراءة كاملة للمقالات، ووضع البحث والتصفية.

## 🚀 متطلبات التشغيل والبدء السريع

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد المتغيرات البيئية:
قم بإنشاء ملف `.env` استناداً إلى `.env.example`:
```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=netnews-617e7
VITE_FIREBASE_STORAGE_BUCKET=netnews-617e7.firebasestorage.app
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### 3. تشغيل الخادم المحلي:
```bash
npm run dev
```

### 4. بناء المشروع للإنتاج:
```bash
npm run build
```

## 🔒 الأمان وقواعد Firestore
يحتوي المشروع على ملف `firestore.rules` لحماية البيانات، وضمان صلاحيات القراءة للعامة للمحتوى المنشور، واقتصار التعديل والإدارة على الحساب المصرح به فقط.
